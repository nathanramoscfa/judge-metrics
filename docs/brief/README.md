# Product brief

`judgemetrics-master-project-specification.xml` is the verbatim product
specification for JudgeMetrics, authored with ChatGPT and provided by the
maintainer on 2026-09-15 (original file name: "JudgeMetrics Master Project
Specification.md"). It is the source document that the root
[`ROADMAP.md`](../../ROADMAP.md) executes.

Where the roadmap departs from the brief, `ROADMAP.md` §2 "Changes from
the original brief" records the change and the reason, and §2 "Brief
phases mapped to roadmap phases" shows where each of the brief's
thirteen development phases landed.

Do not edit the brief. Record decisions in `ROADMAP.md`, the status
document [`docs/ROADMAP.md`](../ROADMAP.md), and `AGENTS.md`.
