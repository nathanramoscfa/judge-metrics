# Phase 3 Step 5 screenshots

The pages Step 5 shipped, in light and dark mode, captured with
Playwright at 1280×900 against the local API over the demo seed
(`uv run poe bootstrap`) on 2026-09-20, for the Step 5 pull request.
Pages: the court page with its own metric panels — Cases and Pretrial
visible, the court-only statutory-release and unknown-actor counts in the
Pretrial panel — and the "Report a data error" action on the header and
on each panel (`court-*.png`; the Comparable judges table and the
judges-serving table follow below the fold); the jurisdiction page v0
with name and type, available years from the coverage window, the courts
table, the data-completeness card per source, and the jurisdiction-level
compare table (`jurisdiction-*.png`); and `/corrections` prefilled from a
judge page's "Report a data error" link — the target summary, the
read-only record type and id, the reason textarea with its limits, the
contact input with the consent line, the optional supporting-material
link, and the "How corrections are handled" card
(`corrections-*.png`).

Every judge, court, and jurisdiction shown is synthetic (the demo
dataset's generated names); no real person or court appears, and no
contact was entered.
